# Engineering rules

- Write the test that fails first, then the code that makes it pass.
- Run the check commands and read their output before saying work is done.
- Keep each change to what the task needs. Note other problems; do not fix them in the same change.
- Prefer deleting code to adding it.
- Do not skip, disable or loosen a test to get a green run.
- When a command fails, find the cause before trying another fix.
